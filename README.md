# Nova 星语输入法（macOS）

[![Release](https://img.shields.io/github/v/release/nova-ime/nova-macos)](https://github.com/nova-ime/nova-macos/releases/latest)
![Platform](https://img.shields.io/badge/macOS-13%2B%20%C2%B7%20Apple%20Silicon-lightgrey)
[![License](https://img.shields.io/badge/license-GPL--3.0-blue)](LICENSE.txt)

整句盲打，一次打对；偶尔打错，按一两个键就能改。

像平时一样把一整句连着打完，Nova 会结合你前面打过的字理解这句话，大多数时候直接按空格就是对的，不用盯着候选框一个词一个词地挑。

- **装上就能用**：安装包经过 Apple 公证，双击安装，第一次使用时选打法，不用改配置文件。
- **本地运行**：模型装在 app 里，打字时不联网，打过的字只留在你的电脑上。
- **跟得上手**：每按一个键约 4 毫秒（Apple 芯片 Mac）。
- **打法齐全**：全拼，以及自然码、小鹤、微软、搜狗四种双拼。
- **全拼更宽容（可选）**：打开「全拼补全」后，没打完韵母也出候选（`muq` → 目前）；支持平翘舌、前后鼻音、n/l、f/h、r/l 模糊音。

**成绩**（详见[测试结果](#测试结果)）：在新闻、对话、小说、网页等 26 个领域的 6486 句里，Nova 逐键打出的整句有 80.6% 一字不差，国内一款知名开源输入法是 61.0%。在另外两款国内知名开源输入法各自公开的测试集上，Nova 的成绩也是最高的。

**技术上**，Nova 是在 [Rime](https://rime.im) 引擎上加了一个约 1 亿参数的 GPT-2 中文模型，每按一个键，由模型给整句候选重新打分。模型以 [uer/gpt2-chinese-cluecorpussmall](https://huggingface.co/uer/gpt2-chinese-cluecorpussmall) 为起点，用约 22 亿字的多领域中文语料继续训练。本仓库是 macOS 版，从[鼠须管](https://github.com/rime/squirrel) 1.1.2 分叉而来。Windows 版在 [nova-windows](https://github.com/nova-ime/nova-windows)。两边的输入方案、词库和模型是同一套。

## 安装

要求 macOS 13 或更新版本，且只支持 Apple 芯片的 Mac（M1 及以后）。

装好的程序叫 `NovaSquirrel.app`（名字沿用自鼠须管），位于 `/Library/Input Methods/`。

1. 到 [Releases](https://github.com/nova-ime/nova-macos/releases/latest) 下载 `Nova-<版本>.pkg`，约 150 MB。
2. 双击安装，按提示输入一次管理员密码。安装包已经过 Apple 公证，不会弹出「无法验证开发者」。
3. 装好后 Nova 会自动加入输入法列表并被选中。第一次切到 Nova 时，会弹出设置窗口让你选打法：
   - 自然码双拼
   - 小鹤双拼
   - 微软双拼
   - 搜狗双拼
   - 全拼

   以后随时可以在菜单栏的星语菜单里换。

   如果输入法列表里没有 Nova 星语，或者切过去打不出字，注销重新登录一次。

升级时直接安装新版本即可，用户词库和设置都会保留。

Nova 可以和官方鼠须管同时安装，两者互不影响。Nova 的用户目录是 `~/Library/NovaSquirrel`，不会读写 `~/Library/Rime`。

**卸载**：删掉 app，然后注销重新登录。
```sh
sudo rm -rf "/Library/Input Methods/NovaSquirrel.app"
```
用户目录 `~/Library/NovaSquirrel` 不会自动删除，不需要的话自己删掉。

## 使用

日常只要记住三件事：

1. **连着打，按空格。** 一整句打完按空格上屏。单按 Shift 切换中英文。
2. **紫色、橙色的词，按数字改。** 紫色是 Nova 替你改过的词，看一眼对不对；橙色多是打错了键。备选列在下面，按数字键换掉它，后面的词会跟着重新算。
3. **改一个字，不用删整句。** 用 `←` `→` 把光标移到打错的地方直接改。

菜单栏的星语菜单里可以：
- 切换五种打法
- 打开「设置…」：选项、使用说明、设置文件夹
- 打开「使用说明」
- 「重新加载设置」

### 颜色

| 颜色 | 含义 |
|---|---|
| 蓝 | 有把握 |
| 橙 | 没把握，下面列出备选。多在打错键时出现 |
| 紫 | Nova 结合上下文改过的词：整句里选了词频更低的那个，值得看一眼 |
| 绿 | 你选过的词，还能再改 |
| 黄底 | 当前焦点 |

### 和普通整句输入法不同的地方

- **选过的词不再变。** 没选过的词会随后面的字重新解码，比如前面打出的「无党」，打完后面的字之后可能改成「武当」。你按数字选过的词，后面的字就不会再改它。
- **全拼没打完的音节也参与候选（可选）。** 在设置 →「选项」打开「全拼补全」后，打 `m`、`muq`、`zhon` 都能直接出候选（`muq` 出「目前」，`zhon` 出「中」），空格直接上屏补全结果。默认关闭；双拼仍只出完整音节的候选，末尾没打完的字母不参与解码。
- **改错不用退格。** Nova 改过的词标成紫色，没把握的词标成橙色，下面直接列出备选，按数字就能改。改了一个词，前面的词保持不动，后面的词会带着新选的字重新解码。
- **光标能停在任意字母上。** 候选面板里显示原始字母，`←` `→` 移动光标。可以只改词里的一个字，也可以在中间增删字母。

### 按键

| 操作 | 按键 | 说明 |
|---|---|---|
| 上屏 | 空格 | 不管光标在哪，整句上屏 |
| 改紫色、橙色的词 | 数字键；`;` 等于 `1` | 前面的词不变，后面的词重新解码 |
| 移到某个词 | `←` `→` 逐个字母；Tab、Shift+Tab 逐个词 | 焦点词是黄底 |
| 换掉焦点词 | `↓` `↑` | 换成下一个、上一个备选 |
| 翻备选 | `-` `=`、`,` `.` 或滚轮 | 每页 6 个，最多 36 个 |
| 只改词里的一个字 | 光标停在那个字的字母上 | 备选先列这个字的同音字：太极 → 太机，「太」不动 |
| 切分错了 | 焦点词上按 `[` 或 `]` | `[` 把最后一个字让给右边的词：和尚｜未 → 和｜尚未。`]` 把右边的第一个字并进来：刘｜荣 → 刘荣。改过的切分会被记住，下次打到同样的字母直接这样切 |
| 改字母 | 光标停在中间时打字、退格、Delete | 只重新解码改动的地方 |
| 回到句尾 | End，或在最后一个词上再按 Tab | |
| 删掉学错的词 | 焦点词上按 Shift+Delete 或 Ctrl+K | 从用户词库里删掉。词库自带的词删不掉，只是取消学到的优先 |
| 辅助码 | 音节后打大写字母，或 `` ` `` 加两个小写字母 | 用形码筛同音字，五种打法都一样。`` ni`re `` 和 `niRE` 都是「你」。默认自然码形码，设置的「选项」里可换小鹤、墨奇 |
| 日期、时间、星期 | `orq`、`osj`、`oxq` | 列出几种写法，按数字或空格选 |
| 表情 | `obq` | 列出 emoji |
| 符号 | `o` 加类别名，如 `ofh`、`osx`、`ojt`；或 `/fh`、`/sx` | |
| 邮箱、网址 | 照常打 `abc@qq.com`、`www.x.cn` | 整段原样上屏 |
| 自定义短语 | 打短语的编码 | 写在设置文件夹的 `nova_phrases.txt`，每行 `文字<Tab>编码`，改了直接生效 |

### 打错键

- **双拼**：双拼按错一个键，编码会变得不成立。这时前面照常出整句，从卡住处到末尾显示成一段橙色的原样字母，备选是改掉一个键之后的写法（相邻键、两键颠倒）。第一次按空格不上屏，而是把多打、漏打一个键的写法也算出来列上；再按一次空格才原样上屏。
- **全拼**：打错时自动纠正，包括相邻键、两个字母颠倒、多打或漏打一个字母。正在打的最后一个音节交给补全，不按打错键纠正。

### 全拼

- 音节可以只打声母：`wm` 我们、`zgr` 中国人、`nihaoshjie` 你好世界（完整拼音中间的 `shi` 也可以只打 `sh`）。
- 没打完也能打：先在设置 →「选项」打开「全拼补全」，之后 `m` 出单字候选，`muq` 出「目前」，`zhon` 出「中」，`ten` 出「疼」；空格直接上屏补全结果。
- 模糊音：平翘舌（zh/z、ch/c、sh/s）、前后鼻音（an/ang、en/eng、in/ing、ian/iang、uan/uang）、n/l、f/h、r/l 默认关闭。在设置 →「选项」打开后，`zongguo` 也能出「中国」。
- `z` `c` `s` 也可以代表 zh ch sh。
- 程序切错音节时，用 `'` 隔开：`xi'an`。
- 全拼和双拼学到的词互通，切换打法不会丢。

### 微软、搜狗双拼

这两种打法用 `;` 表示 ing。只有前一个键是没打完的音节时，`;` 才算拼音，其他时候照旧等于 `1`。

另外它们用 `o` 作零声母键。打到正好是短语编码的组合时（比如 `obq`），会先闪一下短语候选，再打下一个键就恢复正常。

### 学习

- 你改过的词会记进用户词库，下次排得更靠前。
- 用 `]` 并出来的新词，第一次上屏只做记录；同一个词第二次并出来，才写进用户词库。
- GPT-2 模型本身不随你的输入变化。

## 定制

日常设置都在菜单栏的星语菜单 →「设置…」窗口里点选，不用碰配置文件：
- 打法
- 全角字符
- 中文状态下用英文标点
- 全拼补全（没打完的音节也出候选，默认关）
- 模糊音（平翘舌、前后鼻音、n/l、f/h、r/l，只对全拼生效，默认关）

高级用户可以在设置文件夹（`~/Library/NovaSquirrel`，设置窗口「高级」页可以打开）里新建 `nova.custom.yaml`，覆盖方案里的任何设置。改完点菜单里的「重新加载设置」。例如：

```yaml
patch:
  style/show_share: true        # 在词和备选下面显示词频占比
  style/inline_candidate: false # 输入框里显示字母，而不是首选整句
  nova_lm/entity: false         # 不把人名、地名合成一个词块
```

其他文件：
- `nova_phrases.txt`：自定义短语。
- `squirrel.custom.yaml`：字体、字号，即 `style/font_face`、`style/font_point`。鼠须管的配色、圆角、竖排等设置对 Nova 的候选面板不起作用。

## 测试结果

一句话：在新闻、对话、小说、网页等 26 个领域的 6486 句里，Nova 逐键打出的整句有八成一字不差；换成别家公开的测试集，Nova 也是最高的。

下表是首选整句和标准答案逐字相同的比例。Nova 和万象都用自然码；万象测试集按它的规则整串输入，水杉用它自己的评测工具整串输入全拼，其余都是逐键输入：

| | Nova 评测集（6486 句） | 万象测试集（246 句） | 水杉测试集（1631 句） |
|---|---|---|---|
| **Nova** | **80.6%** | **90.2%** | **93.1%** |
| 万象拼音 | 61.0% | 75.2% | 83.8% |
| 水杉 | 48.7% | 没测 | 没测 |

水杉测试集的原始测法是从它的候选里挑一句。按这个测法，Nova 是 96.0%，水杉自己报告里最高的 Qwen3.5-2B 是 95.6%，水杉 24.9M 是 86.8%。

### Nova 自己的评测集：6486 句

句子来自新闻、法律、医疗、小说、网页、对话、评论等 26 个领域，没有参与模型训练。测试工具逐个按键回放，和人打字的过程一样。「上文」指同一篇文章里前面的句子，相当于你已经打出来的文字。

| 配置 | 整句全对 |
|---|---|

- 关掉 GPT-2 后 Nova 不如万象，所以领先主要来自 GPT-2 模型。

| 配置 | 整句全对 |
|---|---|
| **Nova** | **90.2%** |
| 万象（我们复现，自然码） | 75.2% |
| 万象（它报告里的数字） | 66.7% |
| 它报告里的最高分：五笔整句 + 语法模型 | 69.9% |

- 我们复现的万象比它报告里的高 8 个百分点，原因是版本不同：我们用的是万象 pro 18.1.8，它报告测的是更早的版本。
- 246 句里有 33 句在 GPT-2 的训练语料里出现过，都是「第二天早上」这类常见短语。去掉这 33 句，Nova 是 88.7%。

|---|---|---|---|
| **Nova GPT-2（116 MB）** | **96.0%** | 97.2% | **92.4%** |
| Qwen3.5-2B（4bit） | 95.6% | **97.7%** | 89.7% |
| Qwen3.5-0.8B | 94.7% | 97.3% | 87.4% |
| 知意 ML-pumpkin | 92.5% | 94.6% | 86.9% |
| 含章·知微（青简） | 90.4% | 91.2% | 88.3% |
| 含章·通变（青简） | 89.3% | 92.1% | 81.4% |
| 水杉 24.9M | 86.8% | 87.0% | 86.0% |
| 水杉引擎原序（不重排） | 69.3% | 70.1% | 67.4% |

除 Nova 外，其他数字都来自水杉测试集附带的结果文件。带上文时 Nova 只比 Qwen3.5-2B 低 0.5 个百分点，而那个模型的文件是 Nova 的十几倍。

另外，我们也让 Nova 和万象拼音从按键开始自己出整句，不用水杉给的候选。两边都用自然码逐键输入；万象用默认设置，它的上文功能只能拿上一次上屏的文字，喂不进测试集给的上文。

| 句子 | Nova | 万象拼音 |
|---|---|---|
| 水杉打分的 1631 句 | **93.1%** | 83.8% |
| 其中带上文的 1196 句 | **94.6%** | 85.2% |
| 其中不带上文的 435 句 | **88.7%** | 80.0% |

- 1631 句里，只有 Nova 对的 189 句，只有万象对的 38 句。
- 水杉测试集里有 854 句没参与它的打分，因为水杉引擎的候选里没有正确答案。这里一并测了。

- 只看正确答案在它候选里的那些句子，水杉对 83.4%，Nova 对 92.3%。

### 速度

在 Apple 芯片 Mac 上逐键回放 541 句：每键平均 3.96 毫秒，95% 的按键在 5.89 毫秒以内。

### 怎么看这些数字

- **训练语料**：GPT-2 的训练语料和 Nova 评测集来源相近（新闻、小说、网页等）。评测句子没参与训练，但文风相同，Nova 在自己的评测集上占了便宜。在别人的测试集上（万象、水杉），Nova 的总成绩也是最高的。
- **标准读音**：Nova 评测集的拼音是程序自动标注的，本身有少量错误。这些数字适合用来比较不同配置，不能当绝对正确率。
- **按键方式**：Nova 评测集用自然码双拼按键。测水杉时，拼音机械转成了全拼，整串一次输入。
- **没比的**：搜狗、微软拼音等商业输入法没法自动回放，所以没有比。

## 从源码构建

需要 Xcode、Homebrew 的 `ggml`、`boost`、`gh`，以及已经编好的 librime（见 [INSTALL.md](INSTALL.md)）。

```sh
scripts/wanxiang/setup-wanxiang.sh   # 下载万象词库并转成 Nova 的编码
nova-lm/build.sh                     # 编 GPT-2 插件
scripts/build-nova.sh                # 构建 app，模型不在本地时自动下载
sudo scripts/install-nova.sh         # 装到 /Library/Input Methods，要在终端里运行
scripts/package-nova.sh              # 打 .pkg；设了 NOVA_NOTARY_PROFILE 时顺便签名并公证
```

- **模型**：GPT-2 模型和字表不进 git，发布在 [nova-model](https://github.com/nova-ime/nova-model/releases)。
- **安装位置**：Nova 必须装在 `/Library/Input Methods`。装在 `~/Library/Input Methods` 的话，通知中心、锁屏这类系统界面拿到键盘焦点时会把输入法换成 ABC，而且不会换回来。

## 限制

- 只支持 Apple 芯片的 Mac。
- 不支持中英混输。打英文要先按 Shift 切换，或者以大写字母开头。
- 每个词最多 36 个备选。正确的词不在里面时，只能改字母重打。
- 没选过的词会随后面的字改写；想让某个词定下来，按数字选它一下。
